#### 关键架构
- **BattleActionResult 字段**: attacker_side, defender_side, skill, skill_display_name, damage, heal, multiplier, defender_hp_before/after, attacker_hp_before/after, defender_defeated, is_heal, guard_gained, guard_consumed, new_energy, log_messages
- **计算-演出-应用流程**: use_skill() → _calculate_player_action() → pending_result → _set_phase(RESOLVING_PLAYER) → _start_action_timeout() → battle_state_changed.emit() → battle_scene._refresh() → _try_start_presentation() → play_action() → callback → apply_player_result() → _prepare_enemy_action() 或 _finish_battle()
- **输入锁**: `_input_consumed_this_turn` + `current_phase != PLAYER_CHOOSE` 双重判断
- **超时保护**: ACTION_TIMEOUT_SECONDS=4.0, SceneTreeTimer, 超时 emit presentation_timed_out → force_cancel + apply_result
- **HP 条平滑**: resolving 阶段 _refresh() 跳过 HP bar 直接更新，由 presentation._tween_hp_bar() 控制
