# Demo 验收清单

## 实体战斗闭环

- 从草丛、池塘或暖石的遇见面板进入战斗。
- 加载对应的 2D 栖息地战场，双方以实体节点显示；不可出现大幅立绘对峙。
- 玩家可选站位后再释放技能；角色有移动、攻击、受击和回位演出。
- 胜利可结算收服并返回原探索场景；失败不丢进度且能正常返回。

## 三地区域与进度

- 草丛默认开放；第一次收服后开放池塘；完成照料或第二次收服后开放暖石。
- 新档、旧档与备份恢复均得到合法的默认解锁状态。

## 设备与回归

- 在 1280×720、1600×720、1920×1080 横屏下，实体战场、状态栏、技能和结果面板无关键遮挡。
- 键鼠和触控入口不会在对话、面板或战斗过程中向探索角色泄漏输入。
- 运行 `scripts/check-project.ps1`，并在 Godot 编辑器完成一次三场地进入/退出人工回归。
