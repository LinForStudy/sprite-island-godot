# Demo 验收清单

## 实体战斗闭环

- 从草丛、池塘或暖石的遇见面板进入战斗。
- 加载对应的 2D 栖息地战场，双方以实体节点显示；不可出现大幅立绘对峙。
- 玩家可选站位后再释放技能；角色有移动、攻击、受击和回位演出。
- 胜利可结算收服并返回原探索场景；失败不丢进度且能正常返回。

## 六地区域、奖励与进度

- 新建存档后与迎风广场向导交谈，确认叶团团只赠送一次，自动进入小屋与队伍第一格，并获得普通收服球×5、食物×3、清洁工具×3、恢复道具×1。
- 草丛默认开放；草丛首次野外收服后开放池塘；第二次野外收服或首次照料后开放暖石。
- 草丛、池塘、暖石各至少一次野外收服后，确认林间入口和风车开放；风车、山洞、云台各首次收服后按顺序开放下一地区，并在云台显示完成总结。
- 每场胜利确认获得一种收服球和食物或清洁工具；各地区首次成功收服确认额外获得恢复道具×1；失败、取消或库存不足不得写入错误库存。
- 新档、旧档与备份恢复均得到合法且不倒退的解锁状态；重启后确认队伍、背包、图鉴和地区进度保留。

## 设备、设置与回归

- 在 1280×720、1600×720、1920×1080、1366×768 与 844×390 横屏下，HUD、图鉴、小屋、对话、战斗与结果面板无关键遮挡。
- 键鼠和触控入口不会在对话、面板或战斗过程中向探索角色泄漏输入；Esc 与触控返回可关闭对应界面。
- 设置页分别调整主音量、音乐、音效和全屏/窗口，重启后确认设置保留且不影响玩法存档。
- 运行 `scripts/check-project.ps1`、存档/UI/战斗/设置音频/数值 smoke，再在 Godot 编辑器完成一次完整主线人工回归。
