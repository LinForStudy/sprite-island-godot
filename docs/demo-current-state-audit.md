# 萌灵小岛当前原型审计

更新日期：2026-07-29

## 已实现

- 世界探索：两张可加载世界地图、16px 逻辑碰撞网格、相机边界、Y 排序、场景出入口、NPC 对话和六个探索点。
- 数据与进度：六个栖息地、24 只萌灵、首宠赠送、发现/收服/小屋照料、三人队伍、背包、JSON 存档与备份恢复。
- 战斗：六个独立 `Battlefield` 场景、先选左/中/右站位的回合门禁、实体移动/攻击/受击/失败演出、战后奖励与收服、失败进度保留。
- UI 与双端：HUD、图鉴、小屋、通用弹窗、主菜单队伍/背包/设置页、横屏触控、响应式安全区和五种分辨率 smoke。
- 设置与声音：主音量、音乐、音效、全屏/窗口独立保存；世界、战斗、UI、移动、技能、受击和成功收服音效已接入。
- 验证：静态检查、世界/输入/存档/数值/UI/设置音频/战斗统一运行时回归均可执行。

## 当前正式缺口

- 24 套战斗动画尚有 8 套缺失：圆石仔、泥壳龟、晶鼻獾、山心种、云团啾、风筝兔、哨羽鹤、极光小龙；战斗合同因此以 `strict=false` 运行。
- 玩家、迎风向导和部分萌灵仍使用占位或待清理资源；正式美术替换尚未完成。
- 世界视觉布局已数据化为 JSON 并由 TileMapLayer 装配，但仍需在正式美术阶段继续迁移为编辑器内可直接绘制的最终地图资源。
- 尚未完成 Godot 窗口内的完整人工主线回归，以及 Android 真实设备触控验收。

## 当前结论

除上述角色/萌灵正式资源和最终人工设备验收外，单机原型的存档、解锁、队伍、背包、战斗闭环、设置音频和地图运行时契约已具备可重复验证入口。后续应先完成 8 套战斗资源与角色占位替换，再做最终人工封版。
