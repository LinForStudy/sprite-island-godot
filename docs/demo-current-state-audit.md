# 萌灵小岛 Demo 现状审计

更新日期：2026-07-23

## 已实现

- 世界探索：二维俯视移动、碰撞、镜头、场景出入口、NPC 对话与探索点。
- 数据与进度：六个栖息地、二十四只萌灵、发现/收服/小屋照料、JSON 存档和备份。
- 战斗逻辑：属性克制、技能、回合结算、战后收服、结果页和超时保护。
- 视觉基础：草丛、池塘、暖石均已有独立 `Battlefield` 场景与世界素材分层。

## 不符合 Demo 目标的部分

- 现有 `BattleActor` 使用单张 `Sprite2D` 大图，战斗主体仍是图片式对峙。
- 战斗 UI 占用屏幕下方较大面积，尚无玩家主动站位步骤。
- 旧的移动端路线图把部分已实现的战斗、收服、存档列为未来能力，不能作为现状依据。
- 探索地图主要由 `world_scene.gd` 硬编码生成，不适合继续规模化扩展。

## 本轮基线

本轮先将战斗表现重定为独立 2D 实体战场：世界风格战场、实体萌灵、有限站位、回合技能、战后回到探索。草丛、池塘、暖石构成 Demo 内容边界；其余区域为后续储备。
