# 《萌灵小岛》抖音推广视频脚本：30 秒开发日志版

## 使用定位

- 平台：抖音
- 受众：独立游戏开发者、关注游戏开发过程的人
- 形式：Godot 录屏 + 口播 + 短字幕
- 目标：引导关注后续开发
- 语气：真诚开发日志，不包装成已上线成品

## 30 秒口播脚本

> 我最近在 Godot 里做一个怪物收集 RPG 原型，叫《萌灵小岛》。
>
> 一开始，战斗界面很像一个 UI 页面：纯色背景，两张萌灵图贴在上面。
>
> 这次我把它重构成了真正的 2D 草地战场：远处有草坡和树，中间有灌木、花丛，脚下还有站位和阴影。
>
> 现在泡泡汪可以在左下出战，野外的暖尾狐会在右上登场，技能按钮、HP 和能量也都接回了原来的战斗逻辑。
>
> 它还只是原型，但已经开始像一个能长大的小岛了。
>
> 后面我会继续做遇敌、收服、地图和更多萌灵。想看这个 Godot 小游戏怎么长出来，可以点个关注。

## 分镜与画面提示

| 时间 | 口播重点 | 画面建议 |
| --- | --- | --- |
| 0-3 秒 | “我最近在 Godot 里做一个怪物收集 RPG 原型” | 快速切项目运行画面或编辑器 + 游戏画面，第一帧就露出《萌灵小岛》或草地战斗截图。 |
| 3-8 秒 | “以前像 UI 页面，纯色背景，两张图贴上去” | 闪过旧战斗画面或用文字标注“旧版：UI 感太重”。如果没有旧素材，用一帧旧截图/静态对比即可。 |
| 8-16 秒 | “重构成真正的 2D 草地战场” | 展示草地战斗全景：远景草坡、树、灌木、花丛、站位区、前景草叶。镜头可轻微缩放。 |
| 16-24 秒 | “泡泡汪出战，暖尾狐登场，技能、HP、能量接回逻辑” | 录制泡泡汪与暖尾狐对峙，点击普通技能，展示前冲、伤害数字、HP 变化、回位。 |
| 24-30 秒 | “还只是原型，但小岛开始长出来了，关注后续开发” | 切回地图探索、小岛场景或战斗定格，最后叠关注文案。 |

- 不要说“已经上线”“马上可以玩”“完整收服系统已完成”。当前更适合说“原型”“开发中”“后面继续做”。
- 如果 30 秒读不完，优先删掉第二段旧版描述，保留“Godot 原型、草地战场、泡泡汪、暖尾狐、关注开发”。
