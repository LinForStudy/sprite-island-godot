# 2D 实体回合制战斗设计

## 目标

每场战斗切入与栖息地一致的二维小场景。战场使用 TileMap/世界道具、前景遮挡和镜头；玩家与敌方都是场景实体，而非立绘或完整图片背景。

## 回合

1. 回合开始，玩家选择左/中/右三个安全站位之一（每回合一次）。
2. 玩家选择技能，角色在战场中移动、施法、受击、回位。
3. 敌方选择技能并按同样的实体演出结算。
4. 胜利进入收服，失败不扣除发现、收服或解锁进度，返回探索并提示恢复或更换萌灵。

## 资源契约

- 三栖息地十二只萌灵需要 idle、move、attack、hurt、defeat/exit 五类基础动画。
- 每套为透明背景、固定单元格、脚底锚点一致的 SpriteFrames 或精灵表。
- 现有 256×256 PNG 只作为图鉴与过渡回退；不能作为正式战斗动画的验收资源。
- 第一份正式管线样板为 `assets/battle/spirits/leafbun/`，包含生成原图、透明精灵表、四帧和 QC 元数据。

## UI 与输入

UI 仅保留双方状态、回合提示、站位选择、技能、收服和结果，不覆盖主体战场。手机横屏使用左侧虚拟摇杆与右侧交互/确认；战斗站位和技能采用大按钮，键鼠保持调试支持。
